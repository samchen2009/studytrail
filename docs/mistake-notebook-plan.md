# 错题本产品方案

状态：首版已实现（2026-10-22）。本文件保留产品约定；实际入口与验证范围见下方实施说明。

实施说明（自动收录改版）：正常入口改为“一键加入”，由系统完成题图截取、学科与来源回填、知识点分类及保存。逐题解析直接加入；原卷中只选题号；照片与 PDF 通过 Tandix 自动拆题并补充解答，多题时仅勾选要留下的题。原有长表单与手动框选降为可选调整入口。新批改结果同时返回 `questionContent`（完整性、置信度与原图矩形），保存评分后由本机服务自动截图；坐标异常不阻止原评分保存。旧结果先自动截取原作答对照，再按需自动补齐干净题面；纯原作答截图不能进入学生试卷。

自动识题不改动原评分、题目 ID、人工复核或原解析。新照片可以通过模型解题；已有批改答案与解析在补齐题面时保留。任务使用固定 ID、版本记录和原始结果，可重新连接；页面关闭后可从“导入记录”找回原任务，不能因连接中断重复提交。识别中手动修改过题目时拒绝用旧结果覆盖。正常收录无需人工勾选“题面完整”，仅可靠完整的题面直接可组卷；未完整的题目可点“自动补齐题面”。

默认入口：**拍照 / 导入 → 自动拆题 → 选择题目（仅多题时）→ 自动保存**。批改中则是 **加入错题本 → 自动保存**。文字录入、手动修改和截框仅作为识别不理想时的可选办法。

验证：`npm test`、`npm run privacy:check` 通过；虚构数据的浏览器验收覆盖文字录入、公式、图片框选、PDF 翻页旋转、组卷、无答案预览和重启恢复。自动收录测试覆盖真正的像素裁剪、旧题补齐、选择性保存、答案隔离与任务恢复契约；模型结果使用合成返回，未调用真实 Tandix 模型，未执行实体打印或在 Windows 实机验收。

存储：版本 JSON 与独立题图保存在数据目录 `mistakes/`；`indexes/` 可重建，`drafts/` 保存各科选题，`papers/` 保存固定题目版本，`exports/` 保存已请求的打印 HTML，`imports/` 保存自动识题的原页、任务映射及结果。成绩 JSON 备份不包含这些文件，完整备份需复制整个本地数据目录。

首版聚焦三件事：**自动或手动加入错题、按学科查看题目与解答、勾选错题组成新试卷并打印。** 数据继续保存在本机，复用现有批改结果、原卷、解答和版本记录。

不增加独立的错题总览或“全部错题”视图。今日复习、订正任务、待核与待补充分组、掌握判断、已移除列表，以及相应的追踪、提醒和统计均不纳入首版。来源批改已有的判题可靠性规则继续生效，不因此把无法确定的题当作错题。

以下为原首版设计细节；涉及手动加入和题面确认的流程，以以上自动收录改版为准。

## 一 首版目标与范围

| 能力 | 首版范围 |
| --- | --- |
| 自动收集 | 批改结果保存后，提取已确认错误和部分失分题，人工复核优先 |
| 手动加入 | 从批改解析、应用内解答预览、试卷或练习附件预览加入，也能在当前学科直接录入或上传题目 |
| 分学科查看 | 语文、数学、英语、物理、化学、地理分别展示，无全学科列表 |
| 内容查看 | 完整题目、选项、必要材料和图表、原作答、有效评分依据、答案与详细解法 |
| 查询与整理 | 当前学科内按知识点、题型、来源试卷和日期筛选，支持文本搜索与基础标签修改 |
| 历史批改 | 提取已有结构化批改结果，不重新评分或调用模型 |
| 选题组卷 | 当前学科内跨不同来源试卷勾选、排序、设置作答空间，保存新卷 |
| 打印与下载 | 无答案试卷和答案解析分别预览、打印、另存 PDF，并下载离线 HTML |
| 数据保存 | 本地结构化记录、独立资产、可重建索引和固定版本的新试卷 |

本机服务运行时，已有错题的查看、搜索、组卷和打印可离线使用；不因 Tandix 未连接而禁用，也不在进入页面时自动发送材料。

作文等开放题只有整体分数时，首版保留原批改中的建议，不因未满分就把整篇自动收为普通错题。翻译、简答等有明确失分证据的题目可以收录。写作片段专项整理以后扩展。

## 二 页面结构与按学科查看

侧栏新增“错题本”，与“试卷批改”相邻。点击后直接进入学科题目页，不经过统计或任务首页。

```text
错题本              ＋ 手动添加    整理历史批改    已生成试卷

语文    数学    英语    物理    化学    地理

数学错题
搜索题目或知识点    知识点    题型    来源试卷    日期

题目列表                              题目详情
□ 第 12 题 · 函数单调性               完整原题、选项与必要图表
  来源：数学周测                       当时作答、评分依据
  部分失分 · 3/5                       正确答案与详细解析

□ 第 18 题 · 二次函数                 查看原卷对应位置
  来源：数学期中

已选 2 题                             生成试卷
```

示意中的题号、分数和数量为虚构示例。

默认记住当前学生上次选择的学科。首次进入时选择第一个有错题的学科；六科均为空时默认数学，并提供“手动添加”“去批改试卷”和“整理历史批改”。不增加“全部”学科选项。

桌面端使用顶部筛选、题目列表和详情双栏；窄屏使用独立详情页。返回时保留当前学科、筛选、滚动位置和勾选。列表默认每次读取 30 条摘要，详情与图片按需加载。

每个学科的选题篮单独保存。切换学科不丢失该科已选题，返回后恢复。首版生成当前学科的试卷，同一学科可以跨多份来源试卷选题；跨科综合组卷以后再考虑。

### 题目卡片与详情

卡片显示题号或题目摘要、来源、知识点，以及已有的原题有效得分和失分表现。手动加入而没有评分的题不显示虚构分数。原卷分值与参考评分明确区分，不显示学习进度、复习日期、是否掌握等字段。

卡片前有勾选框。勾选后显示“已选 N 题”和“生成试卷”；选题篮可移除单题或清空。这里的移除只取消本次选题，不删除错题。

详情展示已经保存的题干、选项、小问、材料、图表，以及已有的原作答、评分依据、参考答案、分步解法和必要示意图。手动添加可先保存题面，答案解析可以选填或之后补充；未提供时如实显示“尚未提供解答”，不伪造内容。长篇解析按需展开，支持上一题和下一题。

来源链接打开对应试卷，原题号保留在详情与解析导出中。当前批改页仍负责评分复核；错题本首版不增加学生订正表单、重做提交或复习历史。

“已生成试卷”是保存和重印新卷的入口，可按当前学科查看，不作为错题状态分类。

## 三 自动与手动收录入口

自动收集在**批改结果可靠保存后由本机服务触发**，不依赖用户打开错题本或下载评分 PDF。

| 位置 | 控件或反馈 | 行为 |
| --- | --- | --- |
| 上传与批改表单 | “批改完成后自动收集错题”，默认开启 | 控制本次是否自动新增错题 |
| 批改结果概览 | 保存反馈显示新增数量，提供“查看本卷错题” | 打开该学科，并按当前来源试卷过滤 |
| 批改结果更多操作 | “整理或重试错题收集” | 对已保存版本补整理，重复执行不重复入本 |
| 逐题解析卡片 | “已加入 · 查看”或“加入错题本” | 打开已有条目，或按用户意图手动加入，不以 AI 判错为前提 |
| 错题本页头 | “整理历史批改” | 预览历史范围并批量提取结构化结果 |

自动收集开关只控制新增条目。已经收录的题发生评分更正时仍需同步，不能因关闭开关继续显示过时判定。

### 其他页面的手动加入入口

“加入错题本”是题目级通用操作。用户在其他页面看到具体题目时，可以直接加入，不必回到错题本重新找文件或再次 AI 批改。

| 入口 | 加入方式 | 自动带入的信息 |
| --- | --- | --- |
| 试卷批改的逐题解析卡片 | 点击“加入错题本” | 科目、完整题目、作答、评分、答案解析、知识点和来源 |
| 应用内的逐题解答阅读或预览 | 在宿主页面的对应题目操作中点击加入 | 当前题目及已有答案解析，关联原批改任务 |
| 试卷原图查看器 | 选择已有题号，或框选一题后加入 | 科目、试卷、页码、原图区域，以及能可靠关联的题目内容 |
| 考试记录中的试卷、答题卷、答案或练习附件预览 | 框选题目后点击“加入错题本”，可继续选择相关材料块 | 当前考试、科目、附件、页码和所选题图 |
| 错题本当前学科的“＋ 手动添加” | 粘贴或输入题目，上传题图，或从 PDF 选择页面区域 | 当前学科作为默认值，用户可补充来源、知识点和解答 |

成绩总览等没有具体题目的统计卡片不提供把整科数据直接收成一道错题的按钮，可跳转对应试卷或附件后再选题。

已经下载、离线打开的 HTML 或 PDF 不直接写入本机错题数据；离线文件也不嵌入调用本机写接口的脚本。可回到应用内对应题目加入，或使用“手动添加”选择题图。应用内解答预览的加入操作由宿主页面处理，复用受控接口。

### 最简手动加入流程

结构化题目默认自动带齐资料，点击后直接保存并提示“已加入数学错题本”，提供“查看”入口。已经收录时显示“已加入 · 查看”，重复点击不会再建一条题。

图片、PDF 或自由文本没有明确题目结构时，先选择题目范围，打开简短表单。只要求科目，以及文字题干或题图二者至少有一种；题号、来源、知识点、答案解析均可选。科目优先从当前页面继承，仅无法确定时要求选择。题面已含选项、图表或共用材料时应一并选择，支持同题多块、多页，不默认把整份文件当作一道题。

没有评分的题不强制填写得分、满分或错因，没有解答的题可先保存并之后补充。新增、修改题面或补充解答都是内容整理，不引入订正任务、复习记录或其他学习追踪。

手动加入不受自动收集开关影响，也不要求模型先判错。用户可以保存未批改、容易忘或希望再练的题，记录为“用户手动加入”；不因此把原来的全对或待核评分改成错误。

自动和手动收录使用同一套条目、资产、索引和去重服务，同样按学科显示、参与选题与打印。没有干净题面或必要材料的限制，在打印前按同一规则检查，不另建手动错题分类页。

### 自动判定规则

| 来源结果 | 首版处理 |
| --- | --- |
| 已确认错误 | 自动收集，保留作答与失分证据 |
| 已确认部分失分 | 自动收集整道题，并保留正确步骤与具体失分点 |
| 待核、题意无法确认或答案冲突 | 不自动收录，仍在现有批改页处理；错题本不增加独立队列或分类 |
| 原卷无分值，但参考量表已确认存在失分 | 可收录，显式保留参考评分及其依据 |
| 缺少得分或满分的旧结果 | 不推算错误状态或得分率，在来源中确认后再收录 |
| 全对 | 默认不收录 |
| 已确认失分，但缺必要图表或材料 | 仍可在所属学科查看已有内容及原卷；在题目内说明具体缺项，不建立状态分组 |

自动收录不等于教师已经人工核验，详情区分 AI 判定、人工复核与用户手动加入。表中判错限制只决定是否自动收集，不阻止用户主动保存题目；手动加入也不更改原判定。新批改技能与网页当前判分口径的差异，应在批改层独立解决；错题本不自行改判或补分。

首版接在当前完整结果保存后。以后评分与解析拆分时，评分可先收录，解析随后补齐；新增方法或生成导出文件不会再创建一条错题。

### 收录粒度与题目完整性

首版复用现有整道编号题，不根据评分点数量推算小问，也不因最后一问失分就删去其他必要条件。跨页同题只保留一条记录。

阅读文章、实验背景、表格和原图必须随题保存。现有位置字段只是锚点，不足以自动裁出整题；首版保留必要原页，并提供可选的人工框选裁片。人工裁片属于题目资料整理，不产生“待补充”列表或任务系统。

只有学生答卷且图中混有手写答案时，详情标明原页含原作答。首版不承诺自动擦除答案；组成无答案试卷前需补充干净题面或确认适当裁片。

## 四 数据与索引存储

一道错题是一条有稳定 ID 的结构化记录。题目与解答保存为本地版本 JSON，图片保存为独立资产，查询索引是可重建的缓存。

```text
<当前数据目录>/mistakes/
  entries/<错题ID>/                 原题、来源、分类、解答的版本 JSON
  assets/<文件内容哈希>             必要原页、题目裁片与图表
  papers/<新试卷ID>/                选题、题序、设置与版本快照
  exports/<新试卷ID>/<版本>/        无答案试卷与答案解析 HTML
  drafts/                          按学生和学科保存的选题篮与组卷草稿
  indexes/catalog.json             列表摘要、学科与分类索引
  indexes/search.json              题干、解析等可检索文字
  sync/                            来源同步进度与失败重试记录
```

实际根目录取服务配置：手动默认是项目 `.data/`，一键安装入口是安装目录的 `data/`，也可以使用自定义数据目录。

### 每题资料

| 内容 | 保存字段 |
| --- | --- |
| 来源 | 学生实例、科目、收录方式、来源类型、已有的试卷或附件标识、稳定题目身份、题号、原页与源版本；手动题允许没有批改任务 |
| 题面 | 题干、选项、小问、共用材料、图表和必要资产引用 |
| 作答和评分 | 当时作答、人工核对内容、有效得分和满分、评分依据、参考评分说明、给扣分证据 |
| 解答 | 正确答案、分步解析、适用的其他方法、讲解示意图、知识点及其版本 |
| 分类 | 知识点、题型、来源和发现日期，以及必要的标签 |
| 版本 | 原题与解答版本、来源内容指纹、创建与更新时间 |

首版不创建复习尝试目录，不保存学习状态、下次复习日期、掌握等级等字段，也不预建追踪流程。

### 摘要索引

拟定索引中的单题摘要如下：

```json
{
  "id": "错题唯一ID",
  "entryRevision": 3,
  "subject": "数学",
  "collectionMethods": ["manual"],
  "sourceKind": "grading-question",
  "knowledgePointIds": ["函数", "单调性"],
  "questionType": "解答题",
  "sourceJobId": "来源试卷ID",
  "sourceQuestionUid": "来源题目稳定ID",
  "sourceContentHash": "来源题目与有效评分内容指纹",
  "createdAt": "记录创建时间",
  "updatedAt": "记录更新时间"
}
```

`collectionMethods` 记录自动、手动或两者兼有，只是来源元数据，不是学习状态。`sourceKind` 区分批改题目、考试附件、手动上传和手动文本。没有来源批改任务时，对应 ID 为 null，不能编造一个任务或分数；附件来源另保存附件、页码和区域引用。

索引只保存列表和查询需要的摘要，不内嵌图片和整篇解析。Node.js 服务按指定学科过滤，再应用知识点、来源、题型、日期和文本搜索，排序与分页后返回；页面不提供无学科的全量题目视图。

写入先保存主记录，再更新摘要与检索索引。索引通过临时文件写完后替换，更新任务串行处理，避免旧索引覆盖新数据；中断或版本不一致时从主记录重建。列表读取失败不等于主数据丢失。

首版无需外部数据库服务，用户不直接操作 JSON 文件。以后替换索引实现时，保留题目 ID 与主记录契约。

### 资料独立保留

不能只存原卷 URL。错题本需要保留必要内容快照和自己的资产引用，来源试卷移入已删除后仍能读取自己的资料。相同二进制文件可按哈希复用，但不能依赖已删除试卷的访问接口。

新试卷还要固定所选题目与解答版本，避免原错题更新后，已经打印的试卷内容随之改变。

## 五 按学科查询与分类

所有列表、搜索和筛选均在当前学科内进行。切换学科时恢复该科筛选和选题草稿，不出现“全部错题”标签、全科汇总页或学习状态筛选。

| 维度 | 首版规则 |
| --- | --- |
| 知识点 | 复用原批改知识点，可整理别名和修改标签；没有标签仍可查看 |
| 题型 | 根据实际题目或已有标注确定，缺失时不强迫填写 |
| 来源 | 按考试或试卷查询；未关联考试仍能按原批改任务查询 |
| 日期 | 按发现或来源日期筛选，清楚区分两者 |
| 文本 | 搜索题干、选项、知识点和解析已有文字；未识别图片不承诺全文检索 |
| 排序 | 默认最近收录在前，可按来源或题号查看 |

首版不要求用户分析错因、填写下一步行动或完成分类任务。现有评分评语中的具体失分解释可以阅读，但不另建原因追踪体系。

## 六 选题组卷与打印

选题组卷与打印是首版核心能力。用户可从当前学科的多份试卷中勾选题目，组成新的练习卷，并单独生成答案解析卷。

```text
选择学科
  → 搜索或筛选题目
  → 勾选加入该学科选题篮
  → 生成试卷
  → 调整题序、标题与作答空间
  → 检查题面完整性并预览
  → 保存到已生成试卷
  → 打印试卷或另存 PDF
  → 按需单独打印答案解析
```

### 选题与设置

支持单题、多题、跨页和跨来源试卷勾选；提供“全选当前页”，选题篮可查看与取消选择。若以后增加按筛选全部选择，需先展示题数并固定 ID 集合。

| 设置 | 首版规则 |
| --- | --- |
| 标题 | 可编辑，默认使用当前科目生成名称，不带原考试个人成绩 |
| 题序 | 上下移动或拖动，连续生成新题号 |
| 材料 | 阅读或实验背景跟随题组，同一题组的公共材料只打印一次 |
| 小问 | 保留整道编号题和必要小问，精准拆分以后扩展 |
| 作答空间 | 每题可选少、中、多，使用空白或横线 |
| 分值 | 默认不设置，允许单独填写新卷分值，不直接套用每题 10 分的原参考量表 |
| 总分 | 只有全部题目设置有效新分值时才显示 |
| 信息栏 | 作答时间、姓名与日期栏可选，默认不填真实姓名 |
| 纸张 | A4 纵向、黑白友好 |

题目本身缺文章、图表或干净题面时，在组卷检查中逐题指出原因。用户补齐材料或明确取消选择，不能静默少印题，也不能输出关键条件缺失的试卷。这是本次打印的内容检查，不增加错题状态队列。

题面完整但解析未完成时，可先打印无答案试卷。答案解析需要补齐后单独生成，不能宣称已经有完整答案。

### 试卷与解析分别输出

| 成果 | 内容 |
| --- | --- |
| 无答案试卷 | 完整题目、材料、图表、新题号与作答空白；文件中不嵌入答案或原学生作答 |
| 答案解析卷 | 对应新题号的答案、分步讲解、必要图示与知识点 |
| 离线 HTML | 试卷和解析分别下载，所需图片、公式字体等嵌入文件 |
| 打印或另存 PDF | 分别提供打印试卷和打印解析入口，使用浏览器打印 |

不能只通过 CSS 隐藏答案来生成学生试卷。打印页不包含管理侧栏和按钮；长题合理分页，题号、短题和图表尽量避免割裂，保留可用的作答空间。组卷与打印不默认调用 AI。

### 保存与重印

已生成试卷按科目保存名称、题数、创建时间、题序、排版和题目版本，支持再次打开、编辑副本、重新打印。选题篮和组卷草稿保留，以便中途退出后继续。

修改新卷题序、分值或作答空间只影响新卷，不改原考试成绩和错题内容。原错题更新后，只有明确选择采用新版本才生成新版试卷；旧版仍可重印。

首版不记录重做结果、打印次数或是否完成，不把打印行为转化为复习记录。组卷后再次 AI 批改并回流学习追踪，属于后续扩展。

## 七 去重与来源更新

服务端维护稳定题目身份，不单独依赖模型返回的题号或 `q.id`。同一来源页、题号及内容指纹能可靠对应时自动关联；数字、条件、否定词和选项不能为去重而丢弃。

同一结构化题目从不同入口加入时复用同一条记录，并保留收录方式。没有题目 ID 的框选记录，根据原文件、页码及归一到原图的区域识别同一次选择；重复保存请求采用幂等 ID。不同区域、不同条件的题不能只因文字相似就自动合并。

同一结果重复保存、刷新、恢复、补取或重复整理历史，只产生一条记录。跨页同题、多种解法和多个知识点不各自生成新条目。

重新批改后题目无法可靠对应时保留原快照，在来源处提供新旧内容核对，不覆盖另一道题。首版不为此新增独立处理队列。

| 来源变化 | 首版行为 |
| --- | --- |
| 人工改分但仍有失分 | 更新有效评分及来源版本 |
| 复核为全对 | 仅因自动判错收录的条目撤回；有明确手动加入记录的保留，显示更新后的原判定，不再把它说成已确认错误 |
| 来源变成无法确定 | 纯自动条目不继续展示为已确认错题；手动加入的题保留原意并展示实际来源判定，不新建待核分组 |
| 更正识别作答或参考答案 | 更新对应内容，指出旧解析中不再适用的部分，不自行重评分 |
| 只增加解析方法 | 更新解答，不新增错题 |
| 只旋转或校准位置 | 更新展示，不增加题数 |
| 来源试卷被删除 | 已收录错题仍可读取自己保留的题面与解析 |

错题同步失败时显示“评分已保存，错题整理未完成，可重试”。不撤销原评分、不误报同步成功，也不重新调用模型。使用幂等写入，启动时根据已保存结果重试同步；旧任务未显式开启自动收集时，由用户通过历史整理导入。

## 八 现有流程的必要调整

首版只调整支撑错题查看和组卷的流程，不顺便建设学习追踪系统。

| 位置 | 调整 |
| --- | --- |
| 批改结果页 | 增加自动收集反馈和查看本卷错题；打开当前学科，并带来源过滤 |
| 逐题解析与应用内解答预览 | 增加手动加入和查看已有条目的操作，判分复核仍在原流程完成 |
| 原图与考试附件预览 | 支持按题号选择或框选题目后加入，继承科目和来源 |
| 错题本顶部 | 展示当前学科、手动添加、搜索筛选、历史整理、已生成试卷和选题操作 |
| 全局保存提示 | 按当前页面显示本机保存状态，避免已落盘仍提示保存成绩 JSON |
| 导出命名 | 区分成绩 JSON、错题新试卷、答案解析与完整数据备份 |

现有学习提升页面与旧 `learning.issues`、`attempts` 数据保持不变，不在首版迁移、展示或计算掌握状态。完整复习机制以后单独设计。

当前评分与长篇解析一次返回的机制不阻塞首版，可在之后沿用[既有两阶段优化方案](grading-pipeline-plan.md)。额外 AI 讲解、自动拆小问、成绩回填及大范围批改页面重构均不作为本版交付前提。

## 九 历史资料与备份

“整理历史批改”先按当前学科选择来源范围，预览预计收录和重复数量。结果不确定的题仍留在来源批改中处理，不新增错题本待办。

已有结构化结果直接本机提取，不重新评分或调用模型。中断可恢复，重复运行不重复入本。仅有 PDF 或离线 HTML 而没有结构化结果的资料，本版不承诺无损自动导入。

完整备份包括条目、图片与材料、索引、同步记录、选题篮和已生成试卷。索引可重建，主记录和新卷快照不可丢弃。首版可沿用停止服务后复制完整数据目录的方式，完整备份包与自动恢复工具以后扩展。

## 十 首版验收标准

1. 点击错题本后直接按学科查看；没有“全部错题”、今日复习、订正任务、掌握分组或已移除列表。
2. 六科可切换，搜索和筛选均限当前学科；返回时保留当前科目、筛选与选题。
3. 收录规则与批改页有效状态一致，人工复核优先；不确定结果不会被默认当作错误。
4. 结果重复保存、刷新、恢复和整理历史不会重复入本；跨页同题不重复计题。
5. 原题、选项、材料和图表可读，来源可定位，参考分值明确标注。
6. 来源试卷删除后，已收录题仍可读取独立保留的资料；来源复核为全对后撤回纯自动收录，有明确手动加入记录的保留用户选择并更新原判定。
7. 只改旋转、标记位置或导出版本，不产生新错题；重新批改不能错连另一题。
8. 当前学科内可跨页、跨来源选题，切换学科后该科选题仍保留，组卷草稿可恢复。
9. 新卷题号与解析一一对应；调整题序、分值和留白不改原成绩或原题。
10. 缺关键材料时明确列出本次打印不能使用的题，由用户处理，不能静默漏印。
11. 无答案试卷不含参考答案或旧作答；Windows 与 macOS 的 A4 打印覆盖中文、公式、化学式、图表、长题分页和作答留白。
12. 服务重启后可找到错题与已生成试卷，并重印固定版本；原题后续变更不悄悄改变旧卷。
13. 本机已保存、失败重试和索引恢复反馈准确；并发修改不会静默覆盖有效数据。
14. 当前学生实例的数据和草稿隔离，不额外要求 Python、TeX 或数据库服务；已有资料可离线查询和打印。
15. 首版模型与索引不包含学习状态、复习日期、掌握等级和尝试记录，不以预留字段为由提前实现追踪。
16. 批改解析、应用内解答、原卷与附件预览以及当前学科手动添加有明确入口；已有来源信息自动带入。
17. 手动题不依赖 AI 判错，没有评分或解答也可保存；不改原判定、不制造分数，解答缺失如实显示。
18. 同一题从不同入口反复加入不重复；手动加入不受自动开关影响，有明确手动意图的题不会因后续改分被自动丢弃。

## 十一 开发顺序与后续范围

首版依次实施：统一的收录服务与摘要索引、自动收集和其他页面手动加入、分学科列表与详情、历史整理、选题组卷、独立试卷与解析打印、保存与重印。以“自动或手动加入后，能按学科找到题目，并选出来打印”为验收主线。

以后再单独评估复习计划、订正与重做记录、掌握判断、学习问题迁移、AI 变式、写作片段整理和新卷批改回流。没有这些功能不影响首版使用，不在当前页面预留空的入口与看板。
