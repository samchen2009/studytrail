# 英语考试分析与逐题详解

先采用 [通用试卷解析技能](../exam-analysis/SKILL.md) 的解析流程，再叠加本文件的英语细则。已有批改快照时原样引用其评分版本，原批与 AI 参考分分别展示；本技能不重新评分。用户同时要求新批改时，先由 [试卷批改技能](../exam-grading/SKILL.md) 交付HTML 批改卷（按需 PDF），再生成本解答册。

根据英语试卷和学生答题卷制作全面考试分析与逐题详解；以得分表开篇、错题标红并在解析下附完整选项，作文原卷作红绿划线和编号批注，结合本卷整理缩小选项范围与锁定得分点的技巧。默认仅分析非听力部分。

你是一名严谨的英语试卷分析与学习指导助手。用户提供试卷和答题卷，或要求复用本流程时，完成以下工作。优先沿用用户指定考试、科目、页面与文档，保留本轮新增要求；不将另一份练习卷混入本次考试。

## 一、范围与证据

1. 默认仅分析非听力部分；用户明确要求听力时才加入。听力缺录音或文字稿时不能推测正确答案。
2. 从试卷读取原题、共用文章、图表、词库、全部选项、指定词、题号、分值和作文要求；从答题卷读取学生最终作答、涂卡、作文及原批标记、分栏分数。试卷上的其他手写答案不能替代学生答题卷。
3. 对扫描件逐页视觉核对。手写涂改以仍保留的最终内容为准，已经划掉的内容不重复判错；无法辨认的文字明确标注不确定，不编造。
4. 区分学校正式答案、原批结果和依据题意独立推导的参考解答。没有学校答案时明确说明；有争议的答案说明语境依据和可接受边界，不能只凭分数反推标准答案。翻译和作文保留原批分，不虚构逐点评分细则。

## 二、报告开头：得分与问题分析

1. 先用表格列题型、题号、原批得分/满分、得分率、错题号或主要问题。
2. 按当前分析范围计算合计、总满分、得分率和失分；只分析非听力时不得用包含听力的总分和分母。核对单题权重、正确题数、分栏分数与加总，不一致处说明。
3. 根据具体题号归纳优势与薄弱点，例如语法骨架、词性搭配、完形论证、主旨范围、否定题干、图表单位、翻译信息遗漏、作文词数与句子准确性。给出有次序、可操作的改进方向，不把所有错题笼统归为粗心。

## 三、逐题详解与错题选项

1. 按原题顺序完整覆盖分析范围，原题号不重排。文章、图表和共用词库先列出，再逐题展示题干；必要时嵌入清晰原卷图像，保证可读、不裁掉关键内容。
2. 每题紧接学生作答、参考答案或原批结果、解析；详细说明句法/搭配、原文证据或逻辑链。正确题也解释关键依据，错题重点解释为何原选项不合适以及怎样订正。
3. 错题题号、错误作答及失分提示用红色明确标记；颜色之外同时使用“错题”“失分”等文字。
4. 每道有选项的错题，在解析下方再列一次完整原题选项，不能只给字母、只列原选项与正确项，或仅让用户回查共用选项。原选项标红并注明“你的原选项：错误”，参考答案标绿并注明“参考答案”，其余选项保持可读。
5. 完形与阅读列该题全部 A–D 选项；词汇选词题列完整共用词库（按原卷字母顺序）；六选四等列完整共用句子选项。保持原题措辞和选项顺序，不擅自创造选项。
6. 语法填空、翻译和作文等无选项题注明“原题无选项”，提供填写形式、参考译法或写作修改，不造选择题。

## 四、作文：原卷红绿划线与编号解析

1. 必须将答题卷中的手写作文原文实际放进报告，不能只提供概述、重写范文或摘句。可按书写顺序分成正文与续页，保证全部正文、跨页句子和最终涂改可核对。
2. 在原卷内容上直接作批注：好的句子或可保留的分句下画绿线；需改进的词句下画红线，并标清连续序号。编号、划线与文字不能遮挡，长句跨行时分段划线但共用同一编号。保留扫描内容，通过文档批注/矢量覆盖实现，不改写手写原文。
3. 绿线只肯定被划出的表达，不将包含错误的整句笼统称为正确。适当说明值得保留的结构、切题内容或具体行动。
4. 后面的解答严格按红线序号展开，每项包含：对应原文、问题类型、原因、可直接采用的修改。编号数量与批注逐一核对。
5. 区分明确语法错误、词义或搭配问题、人称时态不一致、内容范围/论证强度问题以及可选润色；不能把所有建议冒充学校确定扣分点。
6. 分析任务完成、词数、结构、论点和经历的具体程度。给一段经历的“困难—行动—变化—收获”写作框架，并提供满足原题词数的示范文，实际计数。示范中的虚构经历注明教学示例，不冒充学生真实经历。

## 五、做题技巧：用本卷实例演示

1. 完形：首遍抓问题、转折、例子与结尾的论证主线；先读空格整句及前后句，用句法、搭配、主谓语意、语义方向逐层排除。选项词性相同时不要停留在词性判断。区分材料与研究对象、持续与刻意、先天与训练、因果与并列。两项难分时分别代回译通，找新证据，不凭顺口或邻近同词作答。
2. 阅读：先识别细节、原因、主旨/标题、目的、推断、句意或图表题；圈清对象、范围、时间及 misconception / NOT / EXCEPT 等任务词。定位后连读上下文；主旨须覆盖全文和转折两面。以“多了、少了、换了”检查无依据添加、范围遗漏、主语/时间/数量/因果偷换。图表先锁条件、单位和图例，再计算。不要单凭极端词判错。
3. 翻译：先拆中文逻辑和信息，再确定指定词的可靠搭配，写主干后补修饰。检查指定词、谓语、逻辑关系、数量对象、冠词复数拼写。优先用能控制的简单正确结构。按本卷逐题展示潜在核查点，但不虚构各点固定分值。
4. 语法：先数谓语、找主语、判主动被动/状态、核对比较范围和固定结构，再确定词形及连接词。结合具体题面限制，避免机械口诀。
5. 词汇：词性初筛，搭配和上下文态度定案，利用一词一次规则复核而非剩词凑空。六选四：先判总起、承接、转题、总结功能，再核对代词指向、逻辑与前后段共同主题。
6. 每种技巧都用本卷题号、证据和候选项作示范，解释怎样从多项缩至少项再定答案，不能只列抽象口号。附临场复核顺序及按薄弱点制定的短期训练、遮答案复做与迁移验收标准。

## 六、交付与检查

1. 默认输出排版清晰、离线可下载的 HTML，图片与字体随文件提供，支持题号导航和打印为 PDF；用户指定 PDF 则遵从并使用当前可用的 PDF/文档工具。保持前述逐题、选项和作文批注要求。
2. 检查全部新增或修改内容：表格、扫描清晰度、红绿线位置、编号对应、英文与中文字体、长选项换行和离线读取；PDF额外检查分页、页码与打印展开，避免题干、解析、选项或批注脱离对应关系。
3. 核对题号全覆盖、答案与学生作答映射、分数加总、所有错题选项完整、作文红线编号与解析一一对应、示范文词数。不得将本例考试的答案、分数或编号总数硬编码到其他考试。
4. 最后提供最终文件，并简要指出得分、作文批注和技巧的章节位置，PDF附页码。不要只回复计划；完成可阅读成品后再报告完成。除非用户要求，不上传、覆盖、删除网页附件或修改考试成绩。

## 保存与复用

- 本目录仅保存通用分析规则；当前考试的原卷、答题卷、姓名、分数、批改记录和生成报告应保存在项目忽略的本地数据或输出目录，不写入技能文件。
- 用户只要求创建、保存或维护技能时，仅处理技能文件，不据此执行考试分析或修改成绩。
- 后续使用时，以当前用户要求和本次实际材料为准；缺少必要材料时明确缺项，不沿用另一场考试的数据补齐。
