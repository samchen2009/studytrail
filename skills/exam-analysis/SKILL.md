# 试卷解析：默认离线 HTML，按需 PDF

依据本轮材料和[评分交接约定](../exam-grading/references/handoff.md)制作完整、易查阅的解答册。批改另用 `../exam-grading/SKILL.md`；英语同时读取 `../english-exam-analysis/SKILL.md`，保留其非听力默认范围、完整错题选项与作文细则。

## 证据与成绩

- 先核对本次考试、范围、题号清单与评分版本。逐页视觉确认学生最终作答，区分正式答案、原批、新参考评分与独立推导；不混入其他考试。缺页、模糊、题面笔误和答案争议明确说明，不编造。
- 先主动查找满分与得分：视觉核对卷首/卷尾、题型标题、题号旁括号、答题纸评分栏、分栏标记及正式评分标准；不能仅因文字提取无结果就判缺失。可从明确且完整的逐题分值加总推得全卷满分，并说明来源。完整核查后仍无依据，写“已核对原卷，未标注满分/逐题分值”，不笼统写“未提供”；不能默认全卷100分，也不能把原批得分当作该题满分。
- 已有评分时沿用固定快照。仅分析已批答卷时可读取原批，但不虚构逐题分配或满分；无分值不推算得分率。需要新评分时先运行批改技能，不能在解析里悄悄改分。
- 批改快照已按规则将“未作答”或“作答无法识别”计为失分时，照录分数并保留这两种原因的区别；无法识别不冒充已读到的错误答案，也不在解析阶段擅自改成待核空分。
- 第一页用表格列题型、题号、得分/满分、得分率、错题或主要问题；末列给具体建议。核对单题、题型及全卷合计，只计算当前范围。原批与AI参考分分别列示，缺项标未提供，待核项注明范围。
- 优势与薄弱点引用具体题号，给出有优先次序的改进方向，不把全部问题归为粗心。

## 逐题详解

- 按原题顺序全覆盖，保留原题号。每题先放完整题干和选项，再放学生作答、参考答案、详细解析；共用文章/词库/图表在该题组前展示并明确引用。无选项题注明，不创造选项。
- 原题图像逐题保存为独立 PNG/JPEG 文件，保留题号、源页及裁切坐标；HTML 直接引用，离线下载可另嵌入副本。一键加入错题本复用图像、题干与解答，无需从 PDF 再截图。原卷有图形时优先使用清晰原图裁片，保留条件、单位、图例和刻度；不擅自重画或修改原图。确需辅助图时另标“辅助示意”，不能增加题面未给的条件。
- 正确题解释关键依据；错题重点说明原答案为何不成立、如何订正。错题题号、错误作答及失分提示用红色并配“错题”等文字。选项逐项讲清必要的排除依据，英语按学科技能在错题解析下重列全部原选项。
- 计算与推导写清公式、依据、代入、单位、条件和结论，复核数值与数量级。数学、物理有合适的多种解法时给出并比较适用场景，不以换个措辞凑方法；化学同样可提供适用的独立验证。
- 详略有层次：先给可快速核对的答案与关键思路，再展开完整推导、错因和其他方法；不以重复段落代替详细解释。

## 主观题与原稿批注

- 实际放入完整相关手写原稿，长答和作文可分段/续页，但保持可核对。用矢量覆盖直接在需改进词句下画红线、值得保留的局部下画绿线，并连续编号；跨行同一处问题共用编号，不遮挡字迹和原批。
- 每个红线编号对应“原文—问题类型—原因—可直接采用的修改”；绿线说明具体优点，不把带错误的整句笼统表扬。未作答处不制造原文或下划线。
- 区分明确错误、评分标准要求和可选润色，不冒称某建议是学校确定扣分点。作文补任务完成、结构、内容和表达建议；英语范文与实际词数按英语技能执行。

## 知识点与交付

- 解答后按本卷问题整理知识点，关联题号。数学、物理、化学列公式、定理/规律、符号单位、适用条件、常见误用与解题技巧；语文、英语、地理列材料证据、题型思路、答题结构与排除技巧，必要时补地图/数据处理。
- 每种技巧用本卷实例演示，说明如何缩小范围、找到关键条件或得分点，不能只列口诀。附临场复核顺序、短期训练、遮答案复做及迁移验收标准。
- 默认生成可下载、离线自包含的 HTML；开篇概要，正文逐题，末尾知识点与训练。文字可搜索、复制，提供题号锚点及折叠解析；公式用本地 KaTeX/MathJax，化学式可用 mhchem，图像和字体随文件提供，不依赖 CDN。用户指定 PDF 时遵从，也可从 HTML 打印导出 PDF；不能把“支持LaTeX”当成支持任意TeX宏包。
- 检查全部新增/修改内容：题干/解析对应、完整选项、图像、红绿线位置与编号、公式字体、手机宽度和离线打开；PDF另检查分页与打印时内容完整展开。再核对题号全覆盖、分数加总和评分版本一致。发现评分疑点单列，不静默修改评分。
- 最后交付文件并简要指出得分表、详解和知识点位置；PDF提供页码，HTML提供题号/章节导航。材料及报告放本地 Git 忽略目录；仅保存或维护技能时不执行分析。
