# 学迹 · StudyTrail

一个本地优先的高中学习档案工具。跟踪六科成绩与排名变化，整理考试复盘、试卷附件和学习提升记录。适合学生和家长在自己的电脑上使用。

支持 macOS（含 Apple Silicon / Intel MacBook）、Linux 和 Windows。通过浏览器使用，个人数据保存在运行服务的电脑上。

## 安装与启动

1. 安装 Node.js **24 LTS**（也支持 Node.js 22.13 及以上版本），其中已包含 npm。
2. 从 GitHub 下载项目 ZIP 并解压，或克隆仓库。
3. 在项目目录打开终端，运行：

```sh
npm ci --omit=optional
npm start
```

macOS / Linux 可使用系统终端；Windows 可使用 PowerShell、命令提示符或 Windows Terminal。上述命令在三种系统中相同。首次安装依赖需要网络；安装后本地成绩、附件及 PDF 预览无需外部服务。

浏览器打开 **http://127.0.0.1:8767/**。保持终端运行，按 `Ctrl+C` 停止服务；下次仍在同一目录运行 `npm start` 即可。不要直接双击 `web/index.html`。

第一次打开会提示填写**跟踪对象姓名或昵称、当前年级、学校（选填）**。保存后建立空档案，即可录入考试，也可从已有 JSON 备份恢复。以后可以点击侧栏“对象设置”修改信息。

每个数据目录对应一个跟踪对象。若要跟踪另一位同学，请使用独立数据目录。更改年级或姓名只修改档案，不会删除历史成绩。

更换端口、指定数据目录（所有平台通用，路径有空格时加引号）：

```sh
npm start -- --port 8768
npm start -- --data-dir "./my-data"
npm start -- --port 8768 --data-dir "./my-data"
npm start -- --help
```

默认数据目录是项目下的 `.data/`。相对路径按当前终端所在目录解析。也支持 `PORT` / `GRADES_DATA_DIR` 环境变量；命令行参数优先。本地启动不自动读取 `.env`。升级时保留 `.data/`，不要用全新解压目录覆盖自己的数据目录。

## 数据保存与备份

- 成绩、个人目标和复盘先保存为当前浏览器的草稿，点击“保存到本地 JSON”后写入磁盘。对象设置会直接保存到本地文件。
- 学习提升中的清单与跟踪记录、附件上传会直接保存；尚未提交的文字保留为浏览器草稿。
- 每次保存生成独立版本文件 `.data/000000000001.json`，后续保存不会覆盖旧版本。并发修改会提示冲突并保留草稿。
- JSON 导出包含对象信息、成绩、目标、复盘与学习记录；CSV 用于查看成绩，二者均不包含附件。
- **完整备份请在停止服务后复制整个数据目录**，包含 `instance.json`、全部版本文件和 `attachments/`。恢复时将备份放回，或使用 `--data-dir` 指向备份目录。
- 浏览器草稿尚未写入 JSON，请先保存或导出后再迁移电脑。更换电脑、浏览器或访问端口不会自动搬运浏览器草稿。
- 不同浏览器读取同一服务可共享已保存的记录；不同数据目录的浏览器草稿相互隔离。

默认启动时，如果只有旧 `data/`，会将整个目录迁移为 `.data/`；成绩版本、附件与本地备份一起保留。请先停止旧服务再升级。如果两个目录同时存在，程序会停止自动迁移，要求通过 `--data-dir` 明确选择，避免合并或覆盖档案。指定其他数据目录时不自动迁移。

现有本地数据直接兼容，升级不会重建或覆盖个人成绩、学习记录及附件。旧版本浏览器中尚未保存的同一对象草稿也会尝试恢复；冲突时请先导出草稿再读取磁盘记录。

## 功能与适用范围

目前固定跟踪**语文、数学、英语、物理、化学、地理**六科，年级支持高一至高三。题型满分可以根据实际试卷调整；语文和英语预设模板参考上海考试题型，其他地区使用时请核对。

- **成绩总览**：原始分、得分率、趋势、学科目标和变化分析。
- **排名变化**：百分比、名次和等级分开比较，保留输入原文；缺失值不推算。
- **考试记录与复盘**：题型明细、证据、行动与复查计划，支持 JSON 导入导出及 CSV 导出。
- **学习提升**：学习方法清单、带时间的跟踪记录，兼容旧版详细学习记录。
- **附件**：按考试、科目分类保存试卷、答题卷、答案与练习，支持 PDF / JPG / PNG / WebP；每份最多 20 MB，每批最多 10 份。支持缩放、旋转、PDF 翻页及切换附件。删除后可以恢复；删除考试不会删除磁盘附件。

## 隐私与 Git

个人信息只存于本地数据目录和浏览器草稿中，源码内不附带真实学生档案或成绩。默认服务仅监听 `127.0.0.1`；不包含自动上传、遥测或默认云端连接。PDF.js 资源由本地服务提供。

`.data/`、旧 `data/`、`work/`、`output/`、`outputs/`、`tmp/`、`backups/`、环境文件和常见个人文档格式均已加入 Git 忽略。**自定义数据目录务必放在仓库外，或自行加入 `.gitignore`。** 不要使用 `git add -f` 强制加入个人资料。

未来准备推送前运行：

```sh
npm run privacy:check
```

检查覆盖待发布文件、前端空档案及本地全部 Git 引用中的旧初始数据。历史提交仍含个人档案时检查会失败，必须先在本机备份并清理历史；删除当前文件无法清除旧提交。该检查是项目的防误传措施，发布前仍需审阅实际提交内容。

可选启用推送前检查（需要 Git；ZIP 下载用户无需运行）：

```sh
git config --local core.hooksPath .githooks
```

仓库仅发布通用程序和虚构测试数据；个人档案及旧仓库备份留在本机 `.data/`，不随代码发布。

## 开发与验证

```sh
npm test
npm run privacy:check
```

测试使用临时数据目录和完全虚构的成绩，不读取个人档案。覆盖成绩校验、版本冲突、重启持久化、附件分类与恢复、学习记录、排名解析、首次配置、数据目录隔离和隐私回归。GitHub Actions 已配置 macOS / Linux / Windows × Node.js 22 / 24；实际跨平台结果以将来运行的 CI 为准。

| 路径 | 用途 |
| --- | --- |
| `web/` | 页面、空档案、录入、图表、复盘与草稿 |
| `api/server.js` | 本地 HTTP 服务及成绩接口 |
| `api/store.js` | 本地不可覆盖版本存储及可选云存储适配器 |
| `api/instance.js` | 数据目录实例标识，用于隔离浏览器草稿 |
| `api/attachments.js` | 本地附件接口与归档 |
| `scripts/dev.cjs` | 跨平台启动入口 |
| `scripts/data-directory.cjs` | 旧数据目录迁移，拒绝混合档案 |
| `scripts/privacy-check.cjs` | 发布文件和 Git 历史隐私检查 |
| `tests/`、`check.cjs` | 使用虚构数据的行为测试 |
| `.data/` | 本地个人数据，禁止提交 |

## 可选云端适配器

旧 CloudBase 适配器保留供开发者自行配置，默认本地使用无需安装云 SDK。原先个人试验环境地址已从源码移除，`web/cloud.html` 现在跳转到本地首页。

如自行开发部署，先运行 `npm run cloud:install`，再在服务端配置 `.env.example` 所列的环境 ID、私有桶、允许来源和编辑口令哈希，使用 `npm run cloud:start` 启动接口。云模式显式启用后数据会写入你配置的云服务；它不属于默认本地安装流程，附件也暂不提供云端适配。云适配器仅有模拟测试，尚未作为通用托管方案验证。
